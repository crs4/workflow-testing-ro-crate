# Changelog

## 0.2 (2026-09-25)

* Updated profile to align with [RO-Crate 1.3](https://w3id.org/ro/crate/1.3) and [Workflow RO-Crate 1.1](https://w3id.org/workflowhub/workflow-ro-crate/1.1).
* The IRI mappings for `ComputationalWorkflow`, `FormalParameter`, `input`, and `output` were updated in the [RO-Crate 1.3 JSON-LD context](https://www.researchobject.org/ro-crate/specification/1.3/context.jsonld). This means that from this version onward, Workflow Testing RO-Crate is not backward compatible with RO-Crate 1.1/Workflow RO-Crate 1.0. See the [Workflow Run RO-Crate 0.6 changelog](https://www.researchobject.org/workflow-run-crate/profiles/0.6/changelog) for more details.
